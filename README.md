# Cylion Kenedy Samson — Student Cybersecurity Portfolio

Responsive website sections: Home, About Me, My Projects, Academic Planner, Contacts. Plain HTML, CSS, JavaScript.

## Open the site
Extract the ZIP and serve the folder with a local web server (such as VS Code Live Server), then open `index.html`. Browser storage works best from a local server. The files can be published to GitHub Pages or another static host.

## Files
- `index.html` — content, certification cards, planner, contacts
- `css/styles.css` — desktop and mobile styling
- `js/main.js` — responsive menu, local study uploads, timetable, 10-hour reminder ticker
- `assets/profile.jpeg` — main profile photo
- `assets/certifications/` — certificate images converted from your PDFs
- `docs/` — content and publishing notes

Planner files and activities are stored in the current browser and device only. They are not uploaded or synchronized. The scrolling reminder is shown during the 10 hours before an activity while this website is open. Clearing browser data may remove saved items.

To add a public certificate, copy an existing certificate card in `index.html`, add its image to `assets/certifications/`, and update the title and issue date.
